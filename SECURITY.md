# Security Policy

Thanks for helping keep Vioscribe and its users safe.

## Supported versions

Vioscribe is an early-stage project. Only the latest version on the `main` branch is supported with security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately using GitHub's built-in reporting:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe what you found and, if you can, how to reproduce it.

Helpful details to include:

- What the problem is and where it happens (page, feature, or endpoint)
- Steps to reproduce it
- What an attacker could do with it
- Any screenshots or logs that help (please don't include real users' personal data)

## What to expect

- We'll aim to acknowledge your report within a few days.
- We'll investigate, keep you updated, and fix confirmed issues as quickly as we reasonably can.
- Please give us a reasonable amount of time to fix a problem before sharing it publicly.

## Scope

In scope: the Vioscribe web app and its code in this repository.

Out of scope: problems in third-party services we rely on (such as Supabase, Netlify, or Google sign-in). Please report those to the relevant provider directly.

## Please don't

- Access, change, or delete other users' data
- Run automated scans or attacks that could disrupt the service
- Use social engineering or physical attacks against anyone involved with the project
